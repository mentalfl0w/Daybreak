# 更新记录

[English](CHANGELOG.md) · [项目概览](../README.zh-CN.md)

本记录汇总开发历史。测试和构建条目只反映相应日期记录的证据，不能证明后续改动或所有设备场景都已验证。

## 当前状态 — 2026-11-26

- 在不改变产品入口的前提下整理了应用和基础设施边界。macOS 显示器保护移入 `WallpaperDisplayCoordinator`；仓库存储、校验和保护计算拆成聚焦文件；Bing 传输执行和图片校验从公开 Provider façade 中分离。
- 增加 `scripts/check-import-boundaries.sh`，并在 CI 中检查 Core、平台、移动端、SwiftPM 与 XcodeGen 的依赖方向。
- iOS/iPadOS 与 macOS 时光页均加入地区菜单，仅列出本机有可用缩略图或原图的受支持地区；所选日期仍有效时，切换地区会保留原有导航状态。
- 本次重构验证通过 253 项 DaybreakCore 测试、79 项 MacIntegration 测试、模块边界检查、macOS 无签名 Release 构建和 iOS 无签名 Release 构建。
- 真机文件夹同步、跨设备传播、免费账号重签后的授权书签持久性、完整多显示器和多 Space 验收，以及完整移动端设备行为仍为 **Not tested**。

## 2026-11-27

- 用户安装的 macOS ad-hoc 构建使用 bundle identifier 作为签名标识后，界面显示通知已授权。此前失败的原因与通知实际送达仍未确认。重新构建的 1.2.1 将 macOS 构建号递增至 5。
- 精修移动端设置、同步和快捷指令文案，优先说明用户结果，同时区分本机文件夹写入与跨设备传播，并明确 Daybreak 无法确认系统最终壁纸状态。
- 增加跨平台产品设计与文案规范。移动端和 macOS 界面改动已通过下方记录的无签名构建；真机和完整视觉检查仍为 **Not tested**。

## 2026-11-26

- 为已存在但尚未物化的 iCloud 同步文件增加有界的主动下载请求。同步轮次会报告待处理状态，并在文件提供器完成下载后自动重试。
- 增加由用户主动导出的同步诊断报告。报告使用字段白名单，不会自动上传，也不包含文件夹路径、授权书签、设备名称或用户内容。
- 文件协调与路径校验修改有合成回归测试覆盖。设备报告显示，前几轮会处于 `pendingDownloads`，后续轮次可以完成，因此应用把它视为文件提供器的异步物化过程，不再当作终止性的读取错误。
- 最新 DaybreakCore 测试有 254 项通过。iOS Release 应用使用已安装的 iPhoneOS 27.2 SDK 完成无签名编译。

## 2026-11-25

- 改进 iPhone、iPad 和 Duo 的响应式布局、图片裁切预览、导航及应用内语言切换。这些改动不代表应用能检测 Duo 折叠状态，也不控制系统最终裁切结果。
- 较早记录指出英语复数形式不完整，译文和安全文案需要母语者审校；当前没有记录完整的本地化审计结果。
- 用户反馈称移动端整体使用正常，并确认快捷指令和自动化构图已验收。并非每项场景都提供设备、系统版本和逐步操作记录，因此这不能证明所有设备场景均已验证。
- macOS 继续使用公开的显示器与 Space 事件。多显示器行为和 Space 协调是两项不同能力；完整系统验收、未激活 Space 的更新时机、睡眠和重启行为仍未验证。

## 2026-11-23 起

- 建立共享 Swift 6 数据层，分开获取图片元数据和来源介绍，并提供本地仓库、有界缓存、日历归档以及基于实际观察记录生成的回顾。
- 增加原生 macOS 和 iOS/iPadOS 界面，支持浏览、查看本机归档、收藏和壁纸工作流。移动端通过 App Intents 与快捷指令交接图片，不会直接设置系统壁纸。
- 加入本地优先的数据约束：不编造缺失的故事或日期，不捆绑 Bing 媒体，也不提供系统壁纸备份或恢复功能。

## 验证边界

合成测试和编译只能覆盖代码路径，不能证明系统行为正常。不得据此推断真机或真实系统场景已通过。

仍未验证的场景包括真机同步与免费账号签名行为、完整的多显示器与多 Space 验收，以及移动端各种布局、快捷指令、导出和权限场景。未执行的检查应记录为 **Not tested**。
